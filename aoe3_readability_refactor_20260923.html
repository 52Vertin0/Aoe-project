2 逐 hunk 等价性证明

2.1 isPositionFree（hunk 5+6）——代数等价 + 37.4 万例穷举

原实现是「把候选 footprint 外扩 BUILD_GAP 后逐格与建筑占格求交」，新实现改成标准 AABB 相交测试。 两者都必须严格等价，含边界：

原（逐格三循环）:  ∃i,j :  i ∈ [dr−g, dr+size+g) ∩ [bdr, bdr+bSize)
                          ∧ j ∈ [ur−g, ur+size+g) ∩ [bur, bur+bSize)

新（footprintsOverlap）:
   !( (dr−g)+(size+2g) ≤ bdr  ∨  bdr+bSize ≤ (dr−g)
    ∨ (ur−g)+(size+2g) ≤ bur  ∨  bur+bSize ≤ (ur−g) )
 =  dr+size+g > bdr  ∧  bdr+bSize > dr−g
 ∧  ur+size+g > bur  ∧  bur+bSize > ur−g        ← 与原式逐项相同（半开区间 ⇒ 边界同为严格 >）
被抽出的判据原式新式穷举结果
inBounds !(dr<0 ‖ ur<0 ‖ dr+size>MAP_L ‖ ur+size>MAP_U) dr>=0 && ur>=0 && dr+size<=MAP_L && ur+size<=MAP_U 578 例 / 0 不一致
isBlockedByBuildings 三重循环 + bSize = (HOME‖ARROWTOWER)?2:3 buildingFootprintSize() + footprintsOverlap() 374,544 例 / 0 不一致
isBlockedByResources if (r.Cnt<=0) continue; 逐格比对 i==r.BlockDR && j==r.BlockUR 同式，仅返回值语义反转（命中 ⇒ return true） 同式照搬

求值顺序亦保持原样：边界 → 地图非空 → 地形/高度 → 我方建筑 → 敌方建筑 → 资源 → 狮子规避。 新代码把三处循环按原顺序依次替换为三个 if (... ) return false;，短路行为不变。

穷举脚本按 BUILD_GAP=1、MAP_L/U 任意（边界式与地图尺寸无关）、 建筑 footprint ∈ {2,3}、坐标域 −3…15 全覆盖枚举。命令见 §8。

7 附带观察（非行为变化，供后续清理参考）

  • countBuildings(type, bool, bool, bool) 的 includePending 分支目前零消费点 （两个旧入口都传 false，全文件无 countBuildings(x, true, …) 调用）。 该语义已由 countBuildingsExisting() 覆盖 ⇒ 是个永不被执行的新分支。 不影响行为，但属于「新写死代码」，建议二选一：删掉该参数，或保留并在注释里标明「为后续合并 countBuildingsExisting 预留」。
  • countBuildingsAll(int) 全文件仅 1 处调用（第 1531 行 houseCount）。 它现在只是 4 参版的一个 10 指令转发器。
  • 第 6 个 hunk 的注释「建筑间距检查：候选 footprint 外扩 BUILD_GAP 格内不得与任何建筑相交(含边界)」中， 「含边界」与实现不符：新实现（与原实现一致）在恰好贴边时不算相交（半开区间，严格 >）。 属注释与代码的老口径不一致（非本轮引入），可顺手修正措辞。
